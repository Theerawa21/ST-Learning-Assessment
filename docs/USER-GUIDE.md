# คู่มือผู้ใช้

## ครูผู้สอน

1. เปิดลิงก์ `/exec` ของโรงเรียนด้วยบัญชี Google ที่ได้รับอนุญาต
2. เลือกปีการศึกษาด้านบน แล้วเปิด “รายวิชาของฉัน” ค้นหารหัส/ชื่อ หรือกรองกลุ่มสาระและสถานะ
3. กด “เริ่มวิเคราะห์” หัวเอกสารดึงจากรายวิชาและบัญชีอัตโนมัติ หากไม่มีชุดตัวชี้วัด ให้แจ้งผู้ดูแลก่อน
4. ในแต่ละแถว เลือกตัวชี้วัดที่ประเมินร่วมกัน ระบุสิ่งที่ประเมิน เลือกเครื่องมือหลายชนิด/ระบุอื่น ๆ เลือกช่วงอย่างน้อยหนึ่งช่วง และระบุเกณฑ์
5. กดเพิ่มรายการหรือจะลบแถวได้ ไม่บังคับว่าทุกตัวชี้วัดต้องอยู่ครบสี่ช่วง และไม่บังคับใช้ร้อยละ 70 เสมอ
6. “บันทึกฉบับร่าง” บันทึกข้อมูลที่ยังไม่ครบได้ “ตรวจความครบถ้วน” บันทึกพร้อมแจ้งตัวชี้วัด/ช่องที่ขาด ความครบถ้วนไม่ใช่การรับรองทางวิชาการ
7. เมื่อครบ กด “ส่งตรวจ” และยืนยัน ระหว่างตรวจเนื้อหาถูกล็อก
8. หากถูกส่งกลับ อ่านประวัติ ความคิดเห็นรายข้อและรายแถว แก้ไข บันทึก แล้วส่งใหม่ งานจะเริ่มตรวจที่หัวหน้ากลุ่มสาระเสมอ
9. ฉบับอนุมัติแก้ตรง ๆ ไม่ได้ ใช้ “สร้างฉบับปรับปรุง” เพื่อเก็บฉบับเดิมและเริ่มรุ่นใหม่

ระหว่างบันทึก ระบบปิดการแก้ไขชั่วคราวเพื่อป้องกันข้อมูลที่พิมพ์ใหม่ถูกทับ หากแจ้งว่าข้อมูลเปลี่ยนแล้ว ให้โหลดเอกสารล่าสุดก่อนบันทึก ถ้าการเชื่อมต่อขาดระหว่างคำสั่ง ให้ลองคำสั่งเดิมโดยไม่รีเฟรชก่อน ระบบจำ request ID ในหน้าปัจจุบันเพื่อป้องกันบันทึกซ้ำ

ครูสอนร่วมแต่ละคนจัดทำเอกสารของตนได้ รายการวิชาจะเปิดเอกสารของผู้ใช้คนนั้น ไม่เปิดฉบับร่างของครูอีกคนโดยอัตโนมัติ

## ผู้ตรวจทั้งสามระดับ

“งานรอตรวจ” แสดงเฉพาะขั้นตอนที่ถึงคิวและอยู่ในสิทธิ์ เปิดดูตารางและตรวจ checklist ทั้งเก้าข้อ เลือกผ่าน/ต้องแก้ไข/ไม่เกี่ยวข้อง หากไม่เกี่ยวข้องต้องให้เหตุผล

ระบุข้อเสนอแนะรายข้อ/สรุป/รายแถวได้ “ส่งกลับแก้ไข” ต้องมีข้อเสนอแนะสรุป หากมีข้อที่ต้องแก้ไขจะรับรองไม่ได้ เมื่อครบเลือก “รับรองและส่งต่อ” หรือ “อนุมัติฉบับสมบูรณ์” สำหรับฝ่ายวิชาการ แล้วกดยืนยัน

ผู้จัดทำตรวจงานตนเองไม่ได้แม้มีหลายบทบาท หัวหน้าที่เป็นผู้จัดทำต้องใช้ผู้ตรวจแทนที่ผู้ดูแลมอบหมาย การตรวจอ้างทั้งรุ่นเนื้อหาและสถานะปัจจุบัน จึงต้องเปิดข้อมูลล่าสุดก่อนรับรองแต่ละขั้น

## รายงาน

เปิด “รายงาน” กรองกลุ่มสาระ ครู ระดับชั้น ภาคเรียน และสถานะ เลือก “ดู / ส่งออก” เลือกช่วงประเมินหรือทุกช่วง แล้วสร้าง PDF, DOCX, XLSX หรือ Google Docs

เมื่อ Google สร้างไฟล์สำเร็จ ระบบแสดงลิงก์ไฟล์ ส่วนฉบับยังไม่อนุมัติระบุสถานะไว้ในรายงาน ไม่แสดงผลรับรองปลอม ไฟล์จำกัดสิทธิ์จึงต้องใช้บัญชีเดียวกับที่สั่งสร้าง Google Docs ให้ผู้สั่งสร้างเป็น Editor เฉพาะไฟล์ที่ส่งออกเพื่อแก้ต่อได้ เป็นสำเนาซึ่งไม่เปลี่ยนเนื้อหาหรือผลรับรองในระบบ

## ผู้ดูแลระบบ

ตั้งค่ารายชื่อจริงและบทบาท เพิ่มหลักสูตร/กลุ่มสาระ มอบหมายผู้สอน/ผู้ตรวจแทน นำเข้าตัวชี้วัด และกำหนดชุดอ้างอิงรายวิชาก่อนครูเริ่มทำงาน ผู้ดูแลไม่ได้สิทธิ์รับรองโดยอัตโนมัติ ต้องได้รับบทบาทผู้ตรวจและไม่เป็นผู้จัดทำ

การปิดบัญชีป้องกัน API ครั้งถัดไป แต่สิทธิ์ไฟล์ Google Drive ที่เคยให้เป็นรายไฟล์ต้องบริหารต่อใน Drive ตามนโยบายโรงเรียน ระบบไม่ลบสิทธิ์ไฟล์ย้อนหลังทุกไฟล์โดยอัตโนมัติ

หน้าระบบและสำรองข้อมูลมีตรวจความพร้อม สำรองด้วยตนเอง ติดตั้ง Trigger กู้คืนเป็นสำเนา และรายการคำสั่งค้าง ประวัติการใช้งานแสดงรายการล่าสุด

## ข้อความที่พบบ่อย

| ข้อความ | วิธีดำเนินการ |
|---|---|
| ไม่สามารถอ่านตัวตน Google | ตรวจบัญชี โดเมน และ Deployment; ผู้ดูแลอาจต้องใช้ OAuth |
| บัญชียังไม่ได้รับอนุญาต | ให้ผู้ดูแลเพิ่ม email จริงและเปิดใช้งาน |
| ชุดตัวชี้วัดอ้างอิงไม่ตรงรายวิชา | ตรวจหลักสูตรรุ่น กลุ่มสาระ และระดับชั้นให้ตรงกัน |
| ไม่มีผู้ตรวจแทน | มอบหมายหัวหน้า/ผู้ตรวจแทนที่ไม่ใช่ผู้จัดทำ |
| เอกสารถูกเปลี่ยนแล้ว / ขั้นตอนเปลี่ยนแล้ว | โหลดข้อมูลล่าสุดก่อนแก้ไขหรือตรวจ |
| ข้อมูลยังไม่ครบ | ตรวจรายการที่แจ้ง บันทึกร่างได้แต่ส่งตรวจไม่ได้ |
| ระบบมีรายการค้าง | ผู้ดูแลตรวจ OperationRequests และกู้คืนก่อนใช้งานต่อ |
| Google ส่งออกไม่ได้ | ตรวจ Drive API โควตาและสิทธิ์ของผู้เผยแพร่ |
